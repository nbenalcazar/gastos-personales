# Gastos Personales

## Descripción del problema

Se desarrollará un componente de software en Python para registrar, validar y analizar gastos personales.

El sistema permitirá registrar información de los gastos, validar los datos ingresados, calcular totales y promedios y consultar los gastos según su categoría.

## Objetivo

Desarrollar una solución funcional en Python utilizando GitHub Copilot como asistente de desarrollo, acompañada de pruebas automatizadas con pytest, revisión de calidad y seguridad y documentación técnica.

## Plan de solución

1. Definir las funciones necesarias para gestionar los gastos.
2. Generar el código con apoyo de GitHub Copilot.
3. Revisar, refactorizar y mejorar el código generado.
4. Crear pruebas unitarias con pytest.
5. Crear pruebas de integración con pytest.
6. Ejecutar las pruebas y corregir los errores encontrados.
7. Revisar la calidad y seguridad del código mediante SonarQube for IDE.
8. Corregir los hallazgos identificados.
9. Elaborar la documentación técnica.
10. Crear un Pull Request para revisar e integrar los cambios en la rama principal.
